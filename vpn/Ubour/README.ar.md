# عبور

برنامج ويندوز محمول لتشغيل محرك التجاوز المضمّن دون نافذة أوامر ظاهرة.

## التشغيل

1. فك ضغط الأرشيف كاملًا.
2. شغّل `Ubour.exe` بصلاحية مسؤول.
3. اضغط زر التشغيل داخل البرنامج.

## السلوك

- التصغير يخفي النافذة ويُبقي المحرك عاملًا قرب الساعة.
- زر الإغلاق يوقف المحرك ويغلق البرنامج نهائيًا.
- يفحص البرنامج تحديثات محرك التشغيل الرسمي عند فتحه؛ لا يثبت تحديثًا دون تدخل منك.
- لا يغيّر البرنامج عنوان الإنترنت العام، وليس شبكة خاصة افتراضية.

## التراخيص

توجد تراخيص المحرك والمكوّنات التابعة له داخل مجلد `licenses`.
