---

## Reporting a Vulnerability

The Ubour development team takes security and privacy very seriously. If you discover a security vulnerability or potential exploit, please report it responsibly so we can investigate and patch it before public disclosure.

### How to Report

- **Email**: Send an email with detailed information to: [mohammedjaferalshouha@gmail.com](mailto:mohammedjaferalshouha@gmail.com)
- **GitHub Security Advisories**: You can also report vulnerabilities privately through the **Security** tab of this repository by clicking **Report a vulnerability**.

### What to Include in Your Report

Please provide as much information as possible to help us reproduce and resolve the issue quickly:
1. Type and description of the vulnerability.
2. Affected components (Android APK, Windows client, CiaDPI / ByeDPI native modules, Sing-box integration, DNS filter).
3. Step-by-step instructions or proof-of-concept (PoC) to reproduce the issue.
4. Potential impact and attack scenarios.

---

## Response & Disclosure Process

- **Acknowledgment**: We aim to acknowledge receipt of your vulnerability report within **48 hours**.
- **Investigation & Patch**: We will work on reproducing and resolving confirmed issues as quickly as possible.
- **Credit**: We are happy to credit security researchers who report vulnerabilities responsibly in our release notes.
