# Ubour VPN v1.1.0 - Major Refactor & Automated CI/CD (عبور)

## ✨ New Features & Improvements (الميزات والتحسينات الجديدة)

### 🇸🇦 باللغة العربية:
1. **التحديث الحي المباشر لقواعد منع الإعلانات**: إضافة زر مباشر داخل التطبيق لتحديث وتحميل أحدث قواعد AdGuard و uBlock Origin (أكثر من 182,000 قاعدة) بضغطة زر واحدة دون الحاجة لتحديث التطبيق.
2. **تبسيط الواجهة الرئيسية**: تحسين الشاشة الرئيسية وجعل نفق Cloudflare WARP يتصل تلقائياً بأسرع نقطة سحابية عالمية بضغطة زر واحدة مع إظهار بطاقة خيارات DPI فقط في الأوضاع المخصصة.
3. **مفتاح تبديل المظهر السريع**: إضافة زر شريط العنوان للتبديل الفوري بين المظهر الداكن، الفاتح، وتلقائي النظام.
4. **فصل وتخصيص خوادم أسماء النطاقات (DNS)**: دعم كامل لخوادم Cloudflare, AdGuard, Google, Quad9 والخوادم المخصصة.
5. **أتمتة البناء والتحديثات السحابية (GitHub Actions CI/CD)**: تمكين البناء السحابي الآلي للتطبيق والمحركات عند صدور تحديثات جديدة.

---

### 🇬🇧 In English:
1. **In-App Live Filter Updater**: One-click in-app updater for AdGuard & uBlock Origin adblock rules (182,000+ rules) with live progress tracking.
2. **Streamlined UI & Direct Connection**: Optimized main interface with single-tap instant connection to Cloudflare WARP and dynamic DPI bypass settings.
3. **Quick Theme Switcher**: Dedicated header button to switch seamlessly between System, Dark, and Light themes.
4. **Customizable DNS Engine**: Full separation and support for Cloudflare (1.1.1.1), AdGuard (94.140.14.14), Google (8.8.8.8), Quad9 (9.9.9.9), and Custom DNS servers.
5. **Automated GitHub Actions CI/CD**: Cloud-based automated build & release pipeline for continuous upstream integration.
