# Ubour VPN v1.6.0 - Official Multi-Mode Desktop Release for Windows (عبور)

## ✨ What's New in Ubour Windows v1.6.0 (الميزات والتحسينات الجديدة)

### 🇸🇦 باللغة العربية:
1. **4 أوضاع تشغيل متقدمة**:
   - **نفق كلاود فلير (WARP) + مانع الإعلانات**: تشفير سحابي كامل عالي السرعة عبر بروتوكول WireGuard مع حظر فوري للإعلانات والتعقبات.
   - **مانع الإعلانات فقط**: اتصال مباشر 100% بكامل سرعة مزود الإنترنت مع تصفية الإعلانات محلياً عبر خادم DNS مزدوج (IPv4 و IPv6).
   - **فك حجب المواقع المباشر (GoodbyeDPI)**: تجاوز الحجب عبر تقنيات تجزئة الحزم مع إمكانية اختيار مستوى القوة (-1 المستقر، -5 المتوسط، -9 الأقصى).
   - **خادم VLESS Reality مخصص**: دعم اتصالات Sing-box المشفرة المتقدمة.
2. **محرك تصفية DNS فوري في الذاكرة**:
   - فحص وتصفية فورية بالميكروثانية لأكثر من 182,000 قاعدة من قواعد AdGuard و uBlock Origin بالاعتماد على خوارزمية FNV-1a الفائقة السرعة.
3. **حماية شاملة ضد تسريب DNS**:
   - حظر مسارات DoH و DoT لمنع المتصفحات من تجاوز التصفية وضمان حماية 100%.
4. **واجهة مستخدم عصرية**:
   - دعم كامل للغة العربية والإنجليزية، المظهر الداكن والفاتح، والعمل الهادئ في شريط المهام بجوار الساعة (System Tray).
5. **حزم محمولة جاهزة للتشغيل**:
   - حزم مستقلة لا تحتاج إلى تثبيت لنظامي ويندوز 64-بت و 32-بت.

### 🇬🇧 In English:
1. **4 Advanced Operation Modes**:
   - **Cloudflare WARP + AdBlock**: High-speed encrypted WireGuard cloud tunnel combined with local zero-latency DNS ad & tracker blocking.
   - **AdBlock Only**: 100% direct line ISP speed with local microsecond DNS ad blocking (dual-stack IPv4/IPv6 port 53 listener).
   - **GoodbyeDPI Bypass**: Direct DPI circumvention with customizable profile strength (-1 Stable, -5 Medium, -9 Aggressive).
   - **Custom VLESS Reality**: Direct integration with Sing-box core for advanced proxy connections.
2. **Microsecond DNS Filter Engine**:
   - Ultra-compact in-memory FNV-1a hash matching engine loaded with over 182,000 AdGuard and uBlock Origin filter rules.
3. **Anti-DoH / Anti-DoT Leak Protection**:
   - Prevents browser DNS leaks and ensures 100% network-wide ad & tracker filtering enforcement.
4. **Modern UI & Tray Integration**:
   - Full Arabic & English support, System Dark/Light themes, and seamless background tray minimization.
5. **Zero-Installation Portable Packages**:
   - Standalone, self-sufficient packages for Windows x64 and x86.
