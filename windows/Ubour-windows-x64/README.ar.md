# برنامج عبور لنظام ويندوز (Ubour VPN for Windows)

تطبيق متقدم ومتعدد الأوضاع لتجاوز الحجب وحظر الإعلانات والتعقبات على مستوى الشبكة بالكامل لنظام ويندوز 10 و 11 (64 بت).

## الميزات الرئيسية

- **4 أوضاع تشغيل متقدمة**:
  1. **نفق كلاود فلير (WARP) + مانع الإعلانات**: نفق مشفر فائق السرعة عبر بروتوكول WireGuard مع حظر فوري للإعلانات والتعقبات.
  2. **مانع الإعلانات فقط**: اتصال مباشر 100% بكامل سرعة مزود الإنترنت مع تصفية الإعلانات محلياً عبر خادم DNS مزدوج (IPv4 و IPv6).
  3. **فك حجب المواقع المباشر (GoodbyeDPI)**: تجاوز الحجب عبر تقنيات تجزئة الحزم مع إمكانية اختيار مستوى القوة (-1، -5، -9).
  4. **خادم VLESS Reality مخصص**: دعم مباشر لبروتوكولات Sing-box المتقدمة.
- **محرك تصفية DNS فوري في الذاكرة**: معالجة فائقة السرعة بالميكروثانية لأكثر من 182,000 قاعدة من قواعد AdGuard و uBlock Origin.
- **حماية شاملة ضد تسريب DNS**: منع بروتوكولات DoH/DoT لمنع المتصفحات من تجاوز التصفية.
- **واجهة مستخدم عصرية**: دعم كامل للغة العربية والإنجليزية، المظهر الداكن والفاتح، والعمل في الخلفية بجوار الساعة.
- **برنامج محمول بدون تثبيت**: يعمل مباشرة دون الحاجة لأي خطوات تثبيت معقدة.

## طريقة التشغيل

1. فك ضغط ملف الأرشيف المضغوط بالكامل في أي مجلد.
2. تشغيل الملف `Ubour.exe` بصلاحية مسؤول (مطلوبة لتشغيل محرك اعتراض الحزم وإعدادات DNS).
3. اختيار الوضع المناسب والضغط على زر **اتصال**.

## المحركات والمكوّنات المدمجة

- محرك `sing-box.exe` الإصدار 1.13.19
- محرك `goodbyedpi.exe` الإصدار 0.2.3rc3
- برامج تشغيل اعتراض الحزم `WinDivert.dll` و `WinDivert64.sys`
- مكتبة نفق الشبكة `wintun.dll`
